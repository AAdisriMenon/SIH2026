Technical Algorithms in Production 8 ALGORITHMS

2. Gemini Embedding 2 Dense Retrieval (backend/embedding_service.py)

Projects queries into 768-dimensional normalized semantic vector space using Google Gemini Embedding 2 for dense semantic affinity matching.

3. Hugging Face MiniLM Dense Embeddings (sentence-transformers)

4. Lexical TF-IDF Vector Space Analysis (Sublinear Term Frequency)

Deterministic sublinear term frequency-inverse document frequency vectorizer matching specialized domain vocabulary with cosine similarity.

5. Multi-Model Reciprocal Rank Hybrid Fusion

EMI = [P * r * (1+r)^n] / [(1+r)^n - 1]. Applies official moratorium holidays (e.g. NSFDC Educational Loan course duration + 1 year, or up to 6 months).
